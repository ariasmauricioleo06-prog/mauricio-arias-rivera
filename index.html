HTML,CSS Y JavaScript

Son los tres pilares fundamentales del desarrolo Web que trabajan juntos para crear paginas web dinamicas e interactivas.
HTML se encarga de la estructura y el contenido, CSS del diseñor y la presentacion, y JavaScript de la interactivas y la funcionalidad.

Definicion

HTML (HyperText Markup Language):

Es el lenguaje de mercado que difine la Estructura y el contenido de una pagiana web.Utiliza eqiquetas para delimitar diferentes elementos, como parrafos, encabezados, imagenes, enlaces, etc...

CSS (Cascading Style Sheets):

Es un lenguaje de estilos que utiliza para controlar la presentacion de una pagine web Permite definir aspectos como colores, fuentes, tamaños, margenes, etc..., de los elemntos HTML

JavaScript (Program. Lamguage):

Es un lenguaje de programacion que permite agregar funcionalidad interacitva a una pagina web. Permite manipular elementos, HTML, responder a eventos del usuario, realizar calculos etc...

Analogia de la web y una casa:

HTML

Estructura de la casa.

Es como los cimientos, las paredes, techos, y distribucion de las habitaciones.

HTML, difine la estructura basica de una pagina Web: que elementos hay (titulo, parrafos, botones, imagenes, etc...) pero sin preocupaciones por como se ven.

CSS

Decoracion y estilo de la casa.

Esla pintura de la paredes, el tipo de piso, los muebles, las cortinas el diseño de la cocina.

CSS se encarga de como se ve la pagina: colores, fuentes, margenes alineaciones, estilos responsivos... lo visual.

JavaScript

Los sistemas electricos y electronicos de la casa.

Es como los interruptores que encienden luces, las puertes automaticas, el termostato inteligente.

JavaScript añade funcionalidad e interactividad haciendo que pasen cosas como respuesta a un evento.

Resumen

"Los tres lemguajes son esenciales para el darrollo web, y cada una juega un papel crucial en la creacion de paginas Web modernas y funcionales."
